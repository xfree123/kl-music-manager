              Libraries & Maintenance

              Libraries

              Each library is a folder on this computer. Its tags are indexed in a local database so the app opens it quickly. Removing a library never deletes your music files.

                Maintenance

                Clear cache removes cached album art and the temporary files made for streaming Apple Lossless. Per-library tools: Rescan reads new or changed files, Rebuild re-reads the tags of every file, Clear deletes the indexed metadata (your music files are not changed).
